## Как специалист этим пользуется

1. Новый лот приходит в базу с паспортом (страна, регион, сорт, обработка, высота, плотность, влажность).
2. По `origins` и `varieties` берётся стартовая гипотеза: какая чашка ожидается и как зерно поведёт себя в аппарате.
3. Научные выводы (`literature.md`, раздел «Сводка») задают логику профиля: целевой цвет → длительность фаз → развитие, с поправкой на плотность, влажность и обработку.
4. Каппинг показывает, что сработало; поправки накапливаются в базе обжарок, и эвристики здесь со временем заменяются собственными данными.

## Честность данных

- В литературе ✅ означает, что источник сверен поиском; 📚 — классический источник из базы знаний с ссылкой на поиск по названию.
- Плотность и заметки по обжарке в каталогах — стартовые тенденции, а не замеры. Реальные цифры всегда из базы лотов.
- Сведения о генетике некоторых «эфиопских по типу» сортов (Sidra, Typica Mejorado, Pink Bourbon, Chiroso) основаны на отраслевых отчётах и ещё уточняются.

## План следующих партий

- **Наука, партия 2:** обработка и ферментация (анаэробная, карбоническая мацерация, коферментация), хранение и старение зелёного зерна, дегазация и отдых после обжарки, воздушные обжарочные аппараты (для Ikawa), органические кислоты по сортам.
- **Сорта, партия 2:** полный перечень WCR (55 арабики, 47 робусты), местные сорта Бразилии (Topázio, Acauã, Catucaí), Индии (Chandragiri), Китая и Колумбии.
- **Origins, партия 2:** разбивка по регионам внутри стран (Эфиопия, Колумбия, Кения, Гватемала), известные фермы и станции, призовые лоты Cup of Excellence.
- Пополнение по материалам, которые присылает Борис: каждый новый материал конспектируется в нужный раздел.
