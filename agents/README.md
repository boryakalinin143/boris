# Агенты Бориса

Одиннадцать постоянных агентов внутри проекта «Boris» в claude.ai. У каждого свой системный промпт (`agents/<id>/PROMPT.md`), своя папка-система в этом репозитории и свой дизайн.

Интерактивный хаб со всеми агентами: `agents/index.html`, живая версия https://claude.ai/artifact/F6LpWxvJLsVAcAHMGsvyrg (приватная). Собирается из `hub.template.html` и промптов: `python3 agents/build.py`. Отметки в инструментах хаба хранятся только в браузере.

## Как переключаться между агентами

1. **Список тредов проекта.** Каждый агент — отдельный постоянный тред в проекте «Boris» с его именем в названии. Открыл тред «Людмила, бухгалтер» — говоришь с Людмилой.
2. **Через общий чат проекта.** Напиши в чат проекта, обращаясь по имени: «Людмила, разнеси чек» или «Vadim, профиль для Гуджи». Координатор передаст сообщение в нужный тред.
3. **Хаб.** Страница `agents/index.html`: плитка каждого агента открывает его экран, промпт и инструмент.

Агенты общаются между собой через координатора и по протоколу LOS/1 (см. `life-manager-os/`), если задача касается двух систем.
