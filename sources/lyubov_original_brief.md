# suroast — Brand Brief & Context

> Единый файл-контекст для проекта в Claude. Содержит всё, что было решено по бренду suroast: концепция, нейминг, визуал, цвета, шрифты, продукт, бизнес-модель, финансы и материалы. Передай этот файл модели как источник правды по бренду.

---

## 1. Что это за компания

**suroast** (пишется строчными буквами, одна «r») — specialty-кофе роастери (обжарщик спешелти-кофе) из Праги, Чехия.

**Одна фраза:** «We are turning specialty coffee upside down» — мы переворачиваем спешелти-кофе.

**Суть идеи:** роаст-уровень (степень обжарки) измеряется прибором по шкале Agtron и становится цветом на упаковке. Клиент видит цвет — понимает обжарку. Семь уровней обжарки = семь цветов = визуальный язык бренда.

**Позиционирование:** спешелти-кофе стал вкуснее, но полка осталась «бежевой» — одинаковые белые пакеты, одинаковые tasting notes, один стиль обжарки на все зёрна. suroast делает обжарку видимой, измеренной и честной.

## 3. Логотип и фирменный знак

**Основной знак:** 7 разноцветных точек, разбросанных по сетке (scatter) — каждая точка = один уровень обжарки по Agtron. Это смысловой знак: семь точек = семь роаст-уровней.

**Точные позиции точек** (для воспроизведения, координаты относительно центра, индекс = номер цвета):
```
[-58,-30] цвет0   [-20,18] цвет1   [18,-38] цвет2   [52,8] цвет3
[-40,36] цвет4    [30,40] цвет5    [66,-24] цвет6
```
Радиус точки ~13 единиц. Центр композиции ~ (80,75) в viewBox 160×150.

**Варианты логотипа в паке:** знак (mark), аватар на тёмном, аватар на акцентном, вертикальный (знак + wordmark), горизонтальный, только wordmark, иконка приложения (скруглённый квадрат).

**Wordmark:** слово «suroast» набирается выбранным брендовым шрифтом (см. раздел шрифты).

**Что НЕ использовать:** график roast curve как логотип (отвергнуто — «уйти от графика»), ribbon swoosh как основной знак, спиральные варианты. Scatter из 7 точек — финал.

## 5. Типографика

Статус: **шрифт финально НЕ выбран.** Есть 4 кандидата, по каждому собрана полная презентация + анимация логотипа. Текущий лидер по контексту — Instrument Serif (для инвесторов) или Fraunces (связь с упаковкой).

**Кандидаты:**
1. **Fraunces** — тёплый контрастный серif. Использовался Italic, по просьбе облегчён до regular (вес 400 italic). Связан с упаковкой «In Colour». Классика, солидно, вневременной.
2. **Nabla** — цветной 3D/хромированный дисплейный шрифт (Google Fonts, COLRv1). Вау-эффект, дерзко. Только для заголовков/крупных цифр, не для тела.
3. **Instrument Serif** — изящный высококонтрастный серif (бесплатный, Google Fonts). Премиум, тонкий, дорогой. **Рекомендован для инвесторской презентации.**
4. **Bricolage Grotesque** — смелый современный гротеск (бесплатный, Google Fonts). Любимец Gen-Z 2024–2025. Модно, для молодой аудитории/соцсетей.

**Тело текста везде:** Space Grotesk (sans-serif).

**Про предпочтения:** шрифт должен быть «смелым, но классическим», актуальным ~20 лет, цеплять новое поколение. Все 4 кандидата — бесплатны для коммерции (SIL OFL), кроме Nabla тоже бесплатен.

**Референс по вкусу:** кофейня The Miners (theminers.eu) использует Neue Haas Grotesk Display (чистый швейцарский гротеск = оригинальная Helvetica). Нравится чистота. Бесплатные аналоги: Inter, Manrope, Hanken Grotesk, Archivo.

**Платный шрифт-фаворит одно время:** OHno Type Co. (студия James Edmondson) — Degular (текст), Ohno Blazeface (дисплей), Ohno Casual (рукописный). Цены: Blazeface Family $99, Degular Family $179, Casual $99. Покупка на ohnotype.co, лицензии бессрочные (Desktop/Web/App отдельно).

**Рукописный акцент (бесплатные аналоги Ohno Casual):** Shantell Sans (ближайший), Pangolin, Permanent Marker, Kalam, Caveat, Gochi Hand — все Google Fonts.

## 6. Ключевые концепции бренда

**«True to bean» / «Locus Roast» (философия обжарки):**
Agtron (цвет обжарки) — это пункт назначения, а путь к нему у каждого зерна свой. Два зерна могут прийти к одному Agtron 75 (одинаковый цвет), но разными roast-кривыми: плотная высокогорная Эфиопия идёт долгой мягкой дорогой, мягкая бразильская натуралка — быстрой. **Нет домашнего стиля. У каждого лота своя обжарка.**

**Что такое Agtron:** инфракрасный прибор считывает цвет молотого кофе и даёт число. Чем выше число — тем светлее обжарка.

**Продукт: «Seven boxes. One bag.»** — семь коробок (по одной на уровень обжарки), а пакет внутри одинаковый для всех лотов. Один тираж печати, меньше SKU, меньше отходов.

**На полке:** семь цветов среди стены белых пакетов — то, что гость берёт в руки.

**Artist editions:** шкала как холст — каждый дроп художник оформляет коробку. Инфоповод каждый сезон, повод собрать все семь.

## 13. Ограничения и договорённости по работе

- **Полноценный кастомный шрифтовой файл (.otf со всеми глифами) в сессии не создаётся** — это недели ручной работы. Альтернатива: уникальная леттеринг-надпись «suroast» в векторе (SVG) — свой логотип-wordmark, не требует лицензии.
- **Фото не генерируются** (нет image-генерации) — только вектор/CSS/SVG.
- Бесплатные шрифты (Google Fonts, SIL OFL) легальны для коммерции.
- Веб-артефакты: шрифты только с fonts.googleapis.com/gstatic.com; скрипты с cdnjs/jsdelivr/unpkg.
