# World Coffee Research — Sensory Lexicon, 2-е изд. (2017)

Файл: `WCR_Sensory_Lexicon_v2.0_2017.pdf` (54 стр., англ.). Прислал Борис 2026-10-20.
Разработан Kansas State University (Edgar Chambers IV), проверен в Texas A&M; основа колеса вкусов SCA/WCR (2016) и списков CATA в CVA.

## Что это
Научный словарь: у каждого атрибута есть **определение**, **эталон** (конкретный продукт или вещество) и **интенсивность эталона по шкале 0–15**, плюс рецепт подготовки. Это «линейка» для дескриптивной оценки: интенсивности в CVA (0–15) калибруются по этим эталонам.

## Группы атрибутов
| Группа | Примеры |
|---|---|
| Основные вкусы | сладкий, кислый, горький, солёный |
| Fruity | Berry (клубника, малина, черника, ежевика), Dried fruit (изюм, чернослив), Other (яблоко, груша, персик, виноград, вишня, гранат, кокос, ананас), Citrus (лимон, грейпфрут, апельсин, лайм) |
| Sour/Acid | уксусная, масляная, изовалериановая, лимонная, яблочная кислоты |
| Alcohol/Fermented | виски, винный, ферментированный, перезрелый |
| Green/Vegetative | оливковое масло, сырой, недозрелый, стручок гороха, свежий, тёмно-зелёный, сено, травы, бобовый |
| Stale/Papery | лежалый, бумага, картон |
| Earthy | затхлый/землистый, затхлый/пыльный, плесень, фенольный, животный, мясной, древесный |
| Chemical | резина, нефть, «скунс», медицинский |
| **Roasted** | табак, трубочный табак, **acrid** (резкий от пережаренного), **ashy** (пепел), **burnt**, **smoky**, **roasted**, **brown roast** |
| Cereal | зерно, солод |
| Spices | острый, перец, анис, мускат, корица, гвоздика |
| Nutty / Cocoa | миндаль, фундук, арахис / шоколад, какао, тёмный шоколад |
| Sweet | меласса, кленовый сироп, коричневый сахар, карамелизованный, мёд, ваниль |
| Floral | роза, жасмин, ромашка, чёрный чай |
| Amplitude | общая сила, «слитность», длительность, тело |
| Mouthfeel | сухость во рту, плотность, металлический, маслянистый |

## Пример шкалы (группа Roasted)
«Roasted» по жареному арахису (220 °C): 7 мин = 2,5; 10 мин (средне-коричневый) = 6,5; 15 мин (тёмный) = 9,5; 20 мин (сгоревший) = 15. «Burnt» — пережаренный, резкий, горький, кислый; «Ashy» — сухой, пыльный, остаток сгоревшего (эталон — сильно алкализованное какао).

## Что важно для обжарки
- Ноты группы **Roasted** (acrid, ashy, burnt, smoky) и **Cereal** (grain, malt) — прямые индикаторы профиля: acrid/ashy/burnt = перебор энергии или тёмный цвет; grain/malt и «papery» = недоразвитие или baked; hay/peapod/under-ripe = недоразвитие или незрелое зерно.
- **Stale/papery/cardboard** чаще говорит о старом зерне или хранении, чем об обжарке.
- Чтобы записи в каппинге сравнивались между собой, использовать слова отсюда (они же в CATA-списках CVA).
