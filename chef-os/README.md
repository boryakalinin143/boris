# Personal Chef OS

Личный шеф-повар Бориса (не про suroast): меню на неделю, список покупок для чешских магазинов, холодильник со сроками годности, книга рецептов с режимом готовки, питание, бюджет, обучение и отчёты.

Живое приложение: https://claude.ai/artifact/MGPBa9veYxhmda8zN33fYU (приватное).

## Как устроено

- `app.html` — собранная страница, `src/` — исходники, `build.sh` — сборка.
- Страница работает внутри claude.ai: данные лежат в базе артефакта (`kitchen/state`, читать и писать может только владелец), фото — в хранилище артефакта, шеф-чат и распознавание чеков используют Claude с разрешения пользователя. Вне claude.ai данные сохраняются в браузере, а чат отвечает только по книге рецептов.
- Каталог продуктов (`src/02_data.js`, ~115 позиций): КБЖУ на 100 г, упаковка и цена в Kč. **Цены — оценка на 04.11.2026, не проверены в магазинах**: у приложения нет доступа к каталогам Rohlik, Košík, Tesco, Albert, Lidl, Kaufland, BILLA. Ссылки ведут на поиск по сайтам магазинов.
- КБЖУ и стоимость рецептов считаются из ингредиентов и пересчитываются под число порций.
- Иллюстрации блюд — схематичные тарелки, а не фотографии; в карточку рецепта можно загрузить своё фото.
- Заказы и оплату приложение не оформляет.
