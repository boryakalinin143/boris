## Пять правил, которые закрывают большинство дефектов
1. **RoR постоянно снижается** от Turning Point до выгрузки: без плато, без подъёма после FC (Рао).
2. **Развитие закладывается энергией в начале**, а не растягиванием конца: растянутый конец печёт, обрезанный — недоразвивает.
3. **Каждая партия меряется дважды**: Agtron целое и молотое. Разрыв — главный объективный сигнал недо- или перепечённости.
4. **Газ снижать заранее** (Giesen: за 60–90 с до FC), воздух в средней фазе и на развитии прибавлять.
5. **Не каждый лот на каждый цвет**: безопасное окно проверяется пробами на Ikawa, и только потом цвет попадает в линейку.

Все числа — стартовые ориентиры; после 20–30 обжарок их заменяют собственные данные из базы.
