# SCA Coffee Value Assessment (CVA): сводный конспект

Источники (все в этой папке, присланы Борисом 2026-10-20):
`SCA_CVA_System_to_Assess_Coffee_Value_2024_EN.pdf` (и русский перевод `..._RU_perevod.pdf`), `SCA-102_CVA_Sample_Preparation_2024.pdf`, `SCA-103_CVA_Descriptive_Assessment_2024.pdf`, `SCA-104_CVA_Affective_Assessment_2024.pdf`, `SCA_CVA_Forms_2024_EN.pdf`, `SCA_CVA_Extrinsic_Form_v2_Aug2025.pdf`, `TACCAT_CVA_for_Cuppers_Workbook_RU.pdf`, `SCA_White_Paper_Definition_of_Specialty_Coffee_2021.pdf`.

## Идея
CVA заменяет протокол и форму каппинга SCA 2004 года. Вместо одного балла лот описывается четырьмя **отдельными** оценками; их делают раздельно, чтобы одна не влияла на другую (bias):

| Оценка | Что фиксирует | Как |
|---|---|---|
| **Физическая** (alpha) | цвет зелёного, дефекты на 350 г (кат. 1 и 2), влажность (ёмкостный влагомер, калибровка по ISO 6673, 3–5 замеров), скрин #10–#23 по сетам | форма Physical |
| **Дескриптивная** | что в чашке, объективно: интенсивность + дескрипторы | шкалы 0–15, CATA |
| **Аффективная** | насколько нравится (своё или известное рыночное предпочтение) | 9-балльная шкала, итоговый балл |
| **Внешняя** (extrinsic) | страна, регион, ферма, производитель, сорт, урожай, обработка, станция, грейд, импортёр, сертификаты, награды | чек-лист; заполнять **после** сенсорики |

Определение specialty (SCA, 2021): *кофе или кофейный опыт, признанный за свои отличительные атрибуты и благодаря им имеющий значительную дополнительную ценность на рынке.* Больше атрибутов (вкусовых и информационных) = больше ценности. Балл получается только из аффективной оценки.

## Подготовка образца (SCA-102)
| Параметр | Норма |
|---|---|
| Цвет пробной обжарки | «средний»: L* 26–29 молотого, ≈ плитка Agtron #65; **Agtron Gourmet 63** (Commercial 48, Colorette 3b 96, Colortrack 62); в протоколе 2004: ±1 |
| Время обжарки | в протоколе 2004: 8–12 мин, без подпалин и tipping; в CVA время не задано, но запрещены «слишком быстро» (недоразвитый центр, большой градиент цвета) и «слишком медленно» (baked: хрупкое зерно, приглушённый аромат, зерновые ноты) |
| Если проба с проблемой | не каппировать, переобжарить; отклонение по цвету — сообщить всем сторонам |
| Охлаждение | только воздухом, без воды |
| Отдых | 8–24 ч, герметично, прохладно, темно |
| Доза | 8,25 г на 150 мл объёма чашки (±0,2 г), каждая чашка взвешивается и мелется отдельно |
| Помол | 70–75 % проходит сито US #20 (850 мкм); молоть как можно ближе к заливке (в 2004: не раньше 15 мин) |
| Чашки | стекло/керамика 200–350 мл, диаметр 75–90 мм; аффективная — 5 чашек, дескриптивная — 3–5 или батч-брю 55–60 г/л |
| Вода | 93 ± 3 °C до края; без хлора, Ca-жёсткость 50–175 ppm, щёлочность 40–70 ppm, pH 6–8 |
| Шаги | 1) сухой аромат (fragrance) → 2) залив, корка 3–5 мин, слом 3 движения (aroma) → 3) снять пену, пробовать с ~70 °C минимум 3 раза по мере остывания |
| Сессия | не больше 6 образцов; ложку ополаскивать перед каждой чашкой |

## Дескриптивная оценка (SCA-103)
- Разделы: fragrance, aroma, flavor, aftertaste, acidity, sweetness, mouthfeel. Перед стартом визуально оценить цвет обжарки.
- **Интенсивность 0–15** для каждого раздела (общая сила, не качество). Сдвиг оценки отмечать стрелкой, не стирая.
- **CATA** (отметь всё подходящее): для fragrance+aroma до 5 из: Floral, Fruity (Berry, Dried Fruit, Citrus), Sour/Fermented (Sour, Fermented), Green/Vegetative, Other (Chemical, Musty/Earthy, Woody), Roasted (Cereal, Burnt, Tobacco), Nutty/Cocoa (Nutty, Cocoa), Spice, Sweet (Vanilla/Vanillin, Brown Sugar). Тот же список для flavor+aftertaste (до 5) + **основные вкусы** до 2: соль, кислый, сладкий, горький, умами.
- Mouthfeel: до 2 из Rough, Oily, Smooth, Mouth-drying, Metallic.
- Кислотность и сладость описывают свободными словами (juicy, bright, tart, winey, vinegary…). Сравнения с фруктами для кислотности — плохая практика, путают с ароматом.
- Эталоны вкусов: соль 0,15 % NaCl; кислый 0,015 % лимонной; сладкий 1 % сахарозы; горький — тёмная обжарка ≈ Agtron #35; умами 1 % MSG.

## Аффективная оценка (SCA-104)
- 9-балльная шкала впечатления о качестве (1 «крайне низкое» … 5 «ни высокое, ни низкое» … 9 «крайне высокое») по 8 разделам: fragrance, aroma, flavor, aftertaste, acidity, sweetness, mouthfeel, overall.
- **Неоднородные чашки** — только качественное отличие (другой признак есть/нет), а не сила. **Дефектные чашки** — только potato, moldy или phenolic, с указанием типа и номера чашки.
- **Балл:** `S = 0,65625 × Σh + 52,75 − 2u − 4d`, округление до 0,25. Σh — сумма 8 оценок (8…72), u — число неоднородных чашек, d — дефектных. Примеры: все «5» (Σ40) = 79,0; все «6» (Σ48) = 84,25; все «7» (Σ56) = 89,5.
- Новая шкала шире, чем в 2004: слабые кофе получают ниже, сильные выше. «Интуитивный» итог допустим, если каппер хорошо знает шкалу.
- Combined form: в каждом разделе сначала дескриптив, потом аффектив; внешние данные — в самом конце.

## Что важно для обжарки
- **Пробная обжарка для оценки зерна — ровно Agtron 63 (Gourmet)**, она ближе всего к нижнему краю нашей линейки (65). Для приёмки лотов делать отдельный «каппинговый» профиль на Ikawa под 63 ±1 и не сравнивать каппинги на разных цветах.
- Признаки проблем обжарки, которые прямо названы в стандарте: **слишком быстро** — наружный цвет темнее молотого, тёрпкость и трава; **слишком медленно (baked)** — приглушённый аромат, зерно и хлеб, хрупкое зерно. Разница Agtron зерно/молотый из листа Обжарки — наш объективный индикатор.
- Отдых пробы 8–24 ч; для клиентских профилей на светлых цветах учитывать, что дегазация дольше.
- Горечь (по Handbook): лактоны хлорогеновых кислот 50–70 %, фенилинданы до 30 % (растут на тёмной), кофеин 10–20 %. Терпкость падает с ростом степени обжарки. Кислотность доминирует на светлой, горечь на тёмной.

## Предложение для листа «Каппинг» (coffee-db не трогаю, решать Борису)
Сейчас лист устроен по форме 2004 года (Аромат, Вкус, Послевкусие, Кислотность, Тело, Баланс, Сладость, Чистота, Однородность, Общее, Дефекты, Итог). Чтобы перейти на CVA, без потери старых записей:

| Новая колонка | Тип | Комментарий |
|---|---|---|
| Протокол | список: CVA 2024 / SCA 2004 / Внутренний | чтобы старые строки остались понятны |
| Agtron пробы | число | для CVA-приёмки должно быть 63 ±1 |
| Fragrance инт. / Aroma инт. / Flavor инт. / Aftertaste инт. / Acidity инт. / Sweetness инт. / Mouthfeel инт. | 0–15 | дескриптив |
| Орто-дескрипторы (CATA) | текст, до 5 | fragrance+aroma |
| Ретро-дескрипторы (CATA) | текст, до 5 | flavor+aftertaste |
| Основные вкусы | до 2 | соль/кислый/сладкий/горький/умами |
| Mouthfeel характер | до 2 | Rough/Oily/Smooth/Mouth-drying/Metallic |
| Кислотность: характер / Сладость: характер | текст | свободные слова |
| Fragrance … Overall (8 колонок) | 1–9 | аффектив; старые «Аромат…Общее» оставить для 2004 |
| Неоднородных чашек | 0–5 | |
| Дефектных чашек / Тип дефекта | 0–5 / potato, moldy, phenolic | |
| CVA балл | формула `=ROUND((0.65625*SUM(h1:h8)+52.75-2*u-4*d)*4,0)/4` | |

Колонки «Баланс», «Чистота» и «Тело» в CVA отсутствуют: баланс уходит в Overall, чистота в дефекты и однородность, тело в Mouthfeel. Внешние данные уже есть в листе Лоты, дублировать не нужно. В лист Лоты можно добавить «Скрин, распределение» (проценты по сетам) под физическую форму.
