# Память проекта «Vadim» (обжарка кофе, Борис)

## Правила
- Отвечать по-русски. Оборудование: Giesen 15 кг, Ikawa 50/100 г (в приложении Pro100).
- Линейка Agtron: 65, 75, 85, 95, 105, 115. Agtron Борис меряет по молотому зерну (мелкий помол).
- Борис хочет, чтобы здесь копился весь опыт: каждый профиль, проба, ошибка и вывод. Сохранять сразу, в том же разговоре.
- Перед профилем читать coffee-library/lessons/roast-lessons.md и coffee-db/curves/. После каждой пробы записывать в журнал факт, ошибку прогноза и вывод.
- Перед профилем также просматривать науку: coffee-library/science/literature_2024-2026.md (новейшее, выводы в [[science-2024-2026]]); Борис просил учитывать её всегда.
- Перед профилем также coffee-library/roast-rules.md (свод правил из всех книг, чек-лист). Коротко: [roast-rules-core](roast-rules-core.md). Каждое число помечать: книга / наш замер / гипотеза.

## Уроки
- Нельзя переносить калибровку цвета с одного лота на другой. Цвет считать от температуры крэка.
- Если Agtron 65 на 50 г, на выходе должно быть около 42 г (ужарка 15–16 %; по Рао и Хоосу коридор 15–17 %, выше 17 % — край 2-го крэка).
- Цвет определяют в основном конечная температура зерна и подъём после крэка; время развития вторично (для цвета, но не для вкуса: ±30 с развития заметны в чашке, растянутый хвост даёт печёный).
- Хоос Cultivar даёт времена только для барабана; «крэк на Ikawa 4:15–4:40» — наша гипотеза, не книга.
- Для 65 на Ikawa при раннем крэке цель недостижима без DTR > 30 % или подъёма > 8 °C/мин: отодвигать крэк позже.
- Перед профилем сверяться с книгами по чек-листу: [[profile-checklist-library]].
- Свод правил по книгам с чек-литом: coffee-library/roast-rules.md. Отличать «так в книге» от «наша гипотеза».
- Перед разбором результата уточнять, какой профиль жарили (скрин точек).
