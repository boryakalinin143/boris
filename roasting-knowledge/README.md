# База знаний по обжарке (из проекта Claude «Vadim»)

Здесь лежит всё, что накоплено в проекте «Vadim»: правила обжарки из книг, журнал уроков с реальными пробами Бориса, готовые кривые, база лотов, справочники по сортам и происхождениям, конспекты присланных книг и стандартов SCA. Цель: чтобы любой ассистент (например, в проекте Surroast) знал то же, что и «виртуальный обжарщик», и составлял профили по тем же правилам.

Папка синхронизируется скриптом `scripts/sync_roasting_knowledge.sh` (каждый день, если в проекте что-то появилось). Файлы здесь не правят руками: источник правды остаётся в проекте «Vadim», при следующей выгрузке ручные правки перезапишутся.

## Как ассистенту этим пользоваться

Перед любым профилем обжарки читать по порядку:

1. `coffee-library/roast-rules.md` — свод правил из всех книг (Рао, Хоос, SCA) с чек-листом в разделе 6. Каждое число в профиле помечать: «книга (глава/страница)», «наш замер» или «гипотеза».
2. `coffee-library/lessons/roast-lessons.md` — журнал уроков: каждая проба, ошибка прогноза и вывод.
3. `coffee-db/curves/` — готовые кривые по лотам с результатами (Agtron, вес, крэк) и графиками.
4. `memory/MEMORY.md` — короткая выжимка правил и калибровок Ikawa.

После каждой пробы Бориса (крэк, вес, Agtron, вкус) записывать факт, ошибку прогноза и вывод в журнал уроков и в карточку кривой.

Основные правила проекта:
- Отвечать Борису по-русски.
- Оборудование: Giesen 15 кг и Ikawa 50/100 г (в приложении Pro100).
- Клиентская линейка Agtron: 65, 75, 85, 95, 105, 115 (у suroast ещё PROCESS+). Agtron Борис меряет по молотому зерну.
- Калибровку цвета нельзя переносить с одного лота на другой; цвет считать от температуры крэка.

## Что где лежит

```
memory/                        память проекта: MEMORY.md (индекс) + отдельные заметки
Baza_znaniy.md                 оглавление всех файлов по отделам
SOURCES_PDF.md                 список PDF-оригиналов, которых нет в git, и их конспекты
coffee-library/
  roast-rules.md               свод правил обжарки из книг + чек-лист профиля
  lessons/roast-lessons.md     журнал уроков по пробам
  lineup/                      омни-линейка 65–115 и сверка с портфелем suroast
  materials/                   конспекты книг и материалов Бориса (.md), README с индексом
  origins/                     происхождения (md + csv)
  varieties/                   сорта, группы сортов по Хоосу (md + csv)
  roast-defects/               дефекты обжарки, протокол QC, Agtron 65–115
  market/                      климат, цены на зелёный кофе, бизнес-контекст
  science/                     обзор научной литературы
coffee-db/
  README.md                    описание полей базы лотов
  coffee_db.xlsx               база лотов (Лоты, Обжарки, Каппинг, Справочники)
  curves/                      карточки кривых по лотам + скрины профилей
coffee-miners/                 разбор QC-таблицы Coffee Miners (41 лот) + исходный дамп
```

## Что не выгружается

- PDF-оригиналы книг и стандартов (до 8 МБ каждый): их список в `SOURCES_PDF.md`, рядом с каждым есть конспект `.md`.
- Архив `exports/Baza_znaniy_vse_fayly.zip` и папка загрузок проекта.
- Резюме кандидата (`Rezyume_*`): чужие персональные данные.
