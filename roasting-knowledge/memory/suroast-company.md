suroast (строчными, одна R; Surroast с двумя R — запасное имя) — specialty-обжарочная Бориса в Праге. Борис — CPO, чемпион Чехии по обжарке 2026; Полина Субботина — CFO.
Шкала коробок: NORDIC 115, FJORD 105, DUSK 95, EMBER 85, OBSIDIAN 75, VOID 65, PROCESS+ (экспериментальные обработки, без числа). «True to bean»: у каждого лота своя кривая.
Тарифы для кафе 850/800/760 Kč/кг; модель: 370 Kč кофе на кг готового, потери при обжарке 16 %; зелёного 23 т (Y1) → 78 т (Y5). Сайта нет (suroast.com только планируется).
Источник: репозиторий github.com/boryakalinin143/boris (снимок 03.11.2026; бриф brand/suroast_brand_brief.md — источник правды). Портфель 11 лотов L01–L11 в офисе «Склад» (claude.ai/artifact/1QeX2CX8XqSwSCww2uuMzx) — оценка Claude, ничего не закуплено.
Сверка с омни-линейкой: coffee-library/lineup/suroast-sverka-2026-11-03.md. Связано с [[omni-lineup]].
