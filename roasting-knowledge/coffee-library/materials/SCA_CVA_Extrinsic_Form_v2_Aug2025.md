# SCA CVA — Extrinsic Form v2 (август 2025)
1 стр., новее, чем beta в комплекте 2024. Поля: **Farming** (страна, регион, ферма/кооператив, производитель, вид, сорт, урожай), **Processing** (переработчик, мокрая станция, сухая фабрика, тип обработки: washed/natural/другое, **декаф**, описание процесса), **Trading** (грейд, ICO-номер, импортёр, экспортёр, **farm gate price**, **размер лота**), **Certification** (4C, Fair Trade, Organic, Rainforest Alliance, **Food Safety**), **Other** (награды). Жирным — новое по сравнению с 2024.

Почти всё это уже есть в листе «Лоты»; нет только экспортёра, ICO-номера, farm gate price, размера лота, сертификатов и наград — их можно добавить при желании.
