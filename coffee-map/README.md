# Карта кофе мира

Интерактивная карта: сезоны сбора и прихода свежего урожая в Европу, регионы с высотами и вкусами, сорта, обработки, ценовой уровень и объёмы по странам, импортёры зелёного кофе и страны, где они закупают, биржевые цены и новости урожаев.

Опубликована как артефакт: https://claude.ai/artifact/GpUhjv8dV2jREn4MHNex5j

## Файлы
- `index.html` — страница (d3 + topojson с cdnjs).
- `data/origins.json` — страны, регионы, трейдеры. Собирается скриптом `tools/build_origins.py` из `coffee-library/origins/origins.csv` и `coffee-library/varieties/varieties.csv` (папка проекта) плюс ручные дополнения в самом скрипте.
- `data/market.json` — цены ICE (арабика «C», робуста Лондон), история точек `history_kc`, факты и новости. Этот файл обновляется ежедневно.
- `data/world.json` — границы стран (world-atlas 2.0.2, 50m).

## Ежедневное обновление market.json
1. Найти свежие котировки арабики (¢/фунт) и робусты ($/т) с датой и источником.
2. Обновить `prices`, добавить точку в `history_kc` (одна в день), поменять `updated`.
3. Добавить 1–5 новостей об урожаях, погоде, запасах ICE, регуляторике (EUDR); держать не больше 20, старые убирать.
4. Переопубликовать артефакт по URL выше с `files: {"data/market.json": ...}` и закоммитить файл.

Цифры без источника не вносить. Ценовой уровень происхождений в `origins.json` — ориентир, не котировка.
