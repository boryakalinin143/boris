# suroast — футболка «Czech Roasting Champion looking for investors»

## Что отдавать в печать
Папка `print/` — векторные файлы в реальном размере (текст переведён в кривые, шрифты не нужны):

| Файл | Где | Размер печати |
|---|---|---|
| `back_en_*` / `back_cz_*` / `back_ru_*` | спина, главный текст (EN / CZ / RU) | 300 × 400 мм |
| `back_gym_en_*` | спина, вариант «I LIFT. I ROAST. I RAISE.» | 300 × 400 мм |
| `front_chest_*` | грудь слева, логотип | 100 × 90 мм |
| `front_chest_champion_*` | грудь слева, логотип + «Czech Roasting Champion 2026» | 100 × 100 мм |

`_light` — для светлой майки (голубая / белая), тёмный текст.
`_dark` — для чёрной майки, текст голубой (#CFE6F2), точка Process+ с голубым контуром.

Превью на майке: папка `preview/` (A–F).

## Для типографии
- Цветов много (7 цветов шкалы Agtron + текст) — лучше **DTF или DTG**, шелкография выйдет дорого.
- Голубая майка: ближе к #CFE6F2 (светлый небесный, «вода + молоко»).
- Цвета шкалы: 115 #DCA564 · 105 #C48248 · 95 #A5582A · 85 #8A3E1C · 75 #64260C · 65 #3C1204 · P+ #0A0A0A. Текст #1A120A.
- Фон в файлах прозрачный.
