# SCA — A System to Assess Coffee Value (июнь 2024), англ.
74 стр. Обзор всей системы CVA: история каппинга (Bickford, Lingle 1984, протокол SCAA 1999/2004), четыре оценки (физическая, дескриптивная, аффективная, внешняя), подготовка образца, формы, словарь, FAQ, эталоны ароматов.

Полный конспект с цифрами и предложением для листа «Каппинг»: `CVA_konspekt_i_kapping.md`.

## Что здесь есть сверх стандартов 102–104
- **Combined form**: в каждом разделе сначала дескриптив, потом аффектив; внешние данные в конце. Капперы почти так же точны, как при раздельных каппингах.
- **Проблемы обжарки**: «слишком быстро» — центр не развит, большой градиент цвета; «слишком медленно» — baked, хрупкое зерно, приглушённый аромат, зерновые ноты. Простой универсальной меры нет, учиться по структуре зерна, градиенту цвета и вкусу.
- **Кислотность**: боксы «Dry/Sweet acidity» убраны из-за отсутствия эталонов; характер кислотности только свободными словами. «Фосфорная» кислотность не значит, что фосфорной кислоты много.
- **Ценность**: экономическая, эстетическая, человеческая. Система помогает искать цену, но цену не вычисляет.
- **FAQ по баллу**: шкала шире, чем в 2004; балл только из аффективной оценки; «интуитивный» итог допустим при хорошем знании шкалы, либо брать Overall как прокси.
- Приложение 15: как готовить эталоны ароматов (жасминовый чай, изюм и чернослив, цедра, петрушка, жжёный арахис и т. д.).
